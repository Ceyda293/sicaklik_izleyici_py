# Sıcaklık İzleyici ROS 2 Paketi
Bu paket, rastgele sıcaklık verisi üreten bir sensör düğümü ile bu veriyi dinleyip 30 derecelik eşik değerini aştığında uyarı veren bir izleyici düğümü içerir.
        
**Çalıştırma Adımları:**
1. Sensörü başlatmak için: `ros2 run sicaklik_izleyici_py sensor`
2. İzleyiciyi başlatmak için: `ros2 run sicaklik_izleyici_py izleyici`
